# C Games

A collection of small console games written while practicing C programming.

## Games

- `hangman.c` — Hangman
- `tic-tac-toe.c` — Tic-Tac-Toe
- `Quiz.c` — Quiz game
- `GuessNumber.c` — Number guessing game
- `rockPaperScissor.c` — Rock Paper Scissors
- `simulating_dice.c` — Dice simulation

These programs are mainly practice projects for applying control flow, functions, arrays, strings, random numbers, and user input.
